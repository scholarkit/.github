## 🌟 Apex Scholar

An open-source, AI-powered research workspace built for academic researchers. Apex Scholar unifies literature discovery, knowledge management, LaTeX writing, grant tracking, and secure cloud sync—all in one browser app.

- **Docs Repo**: https://github.com/scholarkit/apexscholar-docs

### ✨ Features

- **Unified Literature Search** – Query ArXiv, Google Scholar, PubMed, Semantic Scholar, and OpenAlex at once
- **AI Insights** – Automatically extract methods, contributions, and gaps from abstracts
- **Knowledge Graph** – Visualize concept clusters and research gaps
- **End-to-End Encryption** – Zero-knowledge security; your data stays private
- **LaTeX Editor** – Write and compile manuscripts in-browser via GitHub Actions
- **Kanban & Grants** – Track tasks and funding deadlines
- **Citation Engine** – Generate BibTeX, APA, MLA, Chicago, and more
- **Chat with PDFs** – Ask questions about uploaded papers

### 🔒 Security & Privacy

All structured data is encrypted client-side (AES-GCM-256) before storage. Not even the storage provider or maintainers can read your research.
